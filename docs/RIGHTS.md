公開展示只用14份資產：3 CSS、4 JS、2 SVG、3 WOFF2、2份 OFL。完整路徑由 scripts/package-site.mjs 的 PUBLIC_ASSETS 列出，不從任意資料夾整包複製。

- The Woven Archive：HERSTORY 原創程式／曲線與其 SVG 輸出，AI 協助製作。人物與現代中文字不是歷史人物、女書字形或史料釋文。專案程式未另授予通用開源 license，公開可讀不等於允許任意再授權。
- Herstory Reading：Adobe Source Han Serif TC 的重命名衍生子集，依 SIL OFL 1.1；保留 assets/fonts/OFL-SourceHanSerif.txt。不是全繁中字集，缺字走系統 fallback。
- Cormorant Garamond 正體／斜體 Latin 子集：Cormorant Project Authors，SIL OFL 1.1，保留 assets/fonts/OFL-CormorantGaramond.txt。
- 系統字體只以 CSS 引用，未複製散布。
- 女書歷史影像及第三方研究截圖不在公開 Repository 或網站中。來源頁的公開瀏覽不等於素材再利用批准。
- 新增材料逐件記錄來源、版本、證據、權利人／license、修改、署名及雙語 alt，依 AGENTS 的公開摘要／internal 分界處理。
